3 — Type scale & spacing notes (for jsPDF)
Layout
An 80px folio rail runs the full page height at the left — a hairline rule, the week/season stamp, and "RESULTS" set sideways in primary light — so the page reads as part of a series. All content sits right of that rule.
Palette (matches the app)
Background #0b1120, header/rail #0a1226, cards #121d35 / #1a2848 alternating, hairlines #1e3566, primary blue #1a47b8 for the poster field, gold #fbbf24 for winners and 1st place, green #22c55e for perfect weeks and upward movement, red #ef4444 for downward movement, silver #94a3b8 / bronze #b45309 for 2nd/3rd.
Type scale (Helvetica, matches jsPDF built-ins)
Poster winner name: 34-36pt bold · Poster points: 46-50pt bold · Storyline index numerals: 20pt bold, muted (#374e6b) · Scoreboard rank #1: 15pt bold gold, others 9-11pt · Section headers: 9pt bold tracked · Micro labels: 6-6.5pt bold tracked uppercase.
Collapse rule
Perfect-week strip and storyline row are each their own block — absent, they're omitted outright and the rule above closes against the next section. Storyline items divide their row evenly by count (1-4).
